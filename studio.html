Connecting an AI service

This Studio is built around an AI Provider Layer — a single adapter module, assets/js/ai-service.js, that sits between this page and any AI model. Every upload already runs through the full pipeline (validate → extract metadata → package a structured payload → call the provider → populate every card above); right now that call simply resolves with "AI Provider Not Connected" because no provider is configured.

To make it real, implement a provider object with methods like analyzeChartImage() and generateTradingSignal() that call an actual vision-capable model and return JSON matching this page's fields, then pass it to AIService.configure(provider). No other file needs to change — not this HTML, not the CSS, not the workflow in studio.js.

Because that call needs an API key, invoking it straight from client-side code exposes the key to anyone viewing the page source. The safe options are a small serverless proxy (a single Cloudflare Worker function, still deployable alongside this static site) or a self-hosted key you control and rotate. That decision is intentionally left for you to make later — nothing here calls out to any service today.
